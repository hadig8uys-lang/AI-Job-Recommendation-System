# AI Job Recommendation System

Final project for the **Building AI** course

## Summary

My idea is to create an AI system that helps people find jobs that match their skills and experience.

## Background

Finding a suitable job can take a lot of time. I chose this idea because I think AI could make job searching easier and faster.

## How is it used?

Users enter their skills, education, and experience. The system compares this information with job descriptions and suggests suitable jobs.

## Data sources and AI methods

I would use sample CVs and job descriptions as data. I could use Bag of Words and TF-IDF to compare text, and K-Nearest Neighbors (KNN) to find similar jobs. I learned these methods in the Building AI course.

## Challenges

The system might recommend unsuitable jobs if the information is incomplete. Privacy and unfair recommendations could also be problems.

## What next?

I would like to test my idea using sample data and improve it as I learn more Python and machine learning.
